# Supplier Directory service

Centralized supplier registry that unifies TrackFlow's two markets (Los Angeles and Zaragoza), replacing the separate spreadsheets kept by Carlos Vega (Carrier Operations) and Ana Whitfield (Warehouse Operations). Built with **FastAPI + TinyDB + Pydantic**. TinyDB is deliberate: the data fits in a JSON file and we will migrate to Postgres once the ORM is ready.

## Data model

| Field | Rules |
| --- | --- |
| `id` | Assigned by TinyDB (response only) |
| `name` | Required, 1-120 characters |
| `country` | Required: `USA` or `Spain` |
| `categories` | Required, at least one of: `carrier_last_mile`, `carrier_international`, `warehouse_supplies`, `packaging_materials`, `reverse_logistics`, `fleet_maintenance`, `it_and_wms_software`, `cleaning_and_facilities` |
| `rate_per_shipment` | Required, greater than 0, in the contract currency |
| `currency` | Required: `USD` for `USA`, `EUR` for `Spain`; any other combination is rejected with `422` |
| `status` | Required: `active` or `suspended` |
| `service_zone`, `contact_email`, `notes` | Optional; `contact_email` must look like an email address |
| `updated_at` | UTC timestamp of the last rate update, generated by the system (set on creation and on every rate change; clients cannot send it) |

Suppliers are suspended, not deleted, when they have a high incident rate. A status change does not move `updated_at`, so it stays a clean history of rate changes.

The field definitions, valid categories and the 15 seed suppliers come from the Supplier Directory section of the root `CONTEXT.md` and live in `supplier_directory/models.py` and `supplier_directory/seed.py`.

## Run

Requires [uv](https://docs.astral.sh/uv/). From this folder:

```bash
uv run seed    # load the initial suppliers (safe to run repeatedly)
uv run serve   # API on http://127.0.0.1:8000, docs at /docs
uv run pytest  # tests
```

The API also seeds an empty database on startup, so it never starts empty. The database file is `data/suppliers.json` (git-ignored); set `SUPPLIERS_DB_PATH` to use another file.

## Endpoints

| Method | Path | Notes |
| --- | --- | --- |
| `POST` | `/suppliers` | `201` with the created supplier; `422` on invalid input |
| `GET` | `/suppliers` | Optional `?country=` and `?category=` filters (case-insensitive) |
| `GET` | `/suppliers/{id}` | `404` if missing |
| `PATCH` | `/suppliers/{id}/rate` | Body `{"rate_per_shipment": 7.5}`; records `updated_at` |
| `PATCH` | `/suppliers/{id}/status` | Body `{"status": "suspended"}` |
| `DELETE` | `/suppliers/{id}` | `200` with the removed supplier; `404` if missing |
| `GET` | `/categories` | Valid categories, used by the backoffice filters and form |

The backoffice page `uis/backoffice/suppliers.html` consumes this API (CORS allows `localhost` origins).
