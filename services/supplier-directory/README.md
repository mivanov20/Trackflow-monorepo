# Supplier Directory service

Lightweight storage API for TrackFlow's procurement suppliers, replacing the spreadsheet the team used before. Built with **FastAPI + TinyDB + Pydantic**. TinyDB is deliberate: the data fits in a JSON file and we will migrate to Postgres once the ORM is ready.

## Data model

| Field | Rules |
| --- | --- |
| `id` | Assigned by TinyDB (response only) |
| `name` | Required, 1-120 characters |
| `country` | Required, 1-80 characters |
| `categories` | One or more of: `Packaging`, `Pallets`, `Labels & Printing`, `Stretch Wrap`, `Handling Equipment`, `Safety Gear` |
| `unit_rate_eur` | Price per unit in EUR, must be greater than 0 |
| `status` | `active` or `suspended` (default `active`) |
| `updated_at` | UTC timestamp generated by the system on create and on every rate or status change; clients cannot send it |

`CONTEXT.md` does not list suppliers, categories, a rate field or statuses, so these were defined for TrackFlow's two warehouses (Los Angeles and Zaragoza) and are recorded in `memory-bank/techContext.md`.

## Run

Requires [uv](https://docs.astral.sh/uv/). From this folder:

```bash
uv run seed    # load the initial suppliers (safe to run repeatedly)
uv run serve   # API on http://127.0.0.1:8000, docs at /docs
uv run pytest  # tests
```

The API also seeds an empty database on startup, so it never starts empty. The database file is `data/suppliers.json` (git-ignored); set `SUPPLIERS_DB_PATH` to use another file. The seed data lives in `data/suppliers_seed.json`.

## Endpoints

| Method | Path | Notes |
| --- | --- | --- |
| `POST` | `/suppliers` | `201` with the created supplier; `422` on invalid input |
| `GET` | `/suppliers` | Optional `?country=` and `?category=` filters (case-insensitive) |
| `GET` | `/suppliers/{id}` | `404` if missing |
| `PATCH` | `/suppliers/{id}/rate` | Body `{"unit_rate_eur": 1.2}`; records `updated_at` |
| `PATCH` | `/suppliers/{id}/status` | Body `{"status": "suspended"}` |
| `DELETE` | `/suppliers/{id}` | `204`; `404` if missing |
| `GET` | `/categories` | Valid categories, used by the backoffice form |

The backoffice page `uis/backoffice/suppliers.html` consumes this API (CORS allows `localhost` origins).
